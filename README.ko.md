# DeepFilterNet3 개인 파인튜닝

[English](README.md) | **한국어**

공개된 [DeepFilterNet3](https://github.com/Rikorose/DeepFilterNet) 잡음 제거 모델을 **내 목소리**와
**내 방 소음** 몇 분으로 파인튜닝하고, 공식 배포판과 같은 ONNX 묶음 형식으로 내보내요.

공개 모델은 DNS 챌린지 데이터로 학습돼서, 마이크와 방에 따라 속삭임·숨소리·작은 말을 잡음으로 보고
지우거나, 선풍기나 특정 키보드 같은 생활 소음을 잘 못 지울 때가 있어요. 공개 체크포인트에서 출발하면
원래의 잡음 제거 능력은 유지하면서 무엇이 내 목소리이고 무엇이 내 소음인지를 배워요.
최근 NVIDIA 그래픽카드에서 몇 분이면 학습이 끝나요.

## 설치

Python 3.10 또는 3.11. 먼저 그래픽카드에 맞는 PyTorch를 설치하세요 ([pytorch.org](https://pytorch.org)). 예:

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
pip install --no-deps deepfilternet==0.5.6
```

`deepfilternet`은 예전 버전을 고정해 두고 있어서 의존성 없이 설치하고, 필요한 패키지는
`requirements.txt`에 따로 적었어요. 새 torchaudio에서 필요한 작은 호환 코드는 `common.py`에 있어요.

## 사용법

```bash
python record.py      # 안내에 따라 녹음: data/voice (평소 말, 작은 말, 속삭임, 숨소리), data/noise (키보드, 마우스, 책상, 방 소리)
python finetune.py    # 약 2000 스텝, 끝나면 학습 전후 비교를 보여줘요
python enhance.py 녹음.wav   # 들어보기용 *_public.wav, *_tuned.wav를 만들어요
```

잡음 제거를 실제로 쓸 마이크, 게인, 방에서 녹음하세요. 갖고 있는 녹음을 써도 돼요.
깨끗한 목소리 녹음은 한 폴더에, 잡음만 있는 녹음은 다른 폴더에 넣고 `--voice`, `--noise`로 지정하면 돼요.
샘플레이트는 상관없어요 (모두 48 kHz로 바꿔요).

`finetune.py`는 `out/`에 이런 파일을 만들어요.

| 파일 | 내용 |
| --- | --- |
| `DeepFilterNet3_personal/` | 배포판과 같은 구조(`config.ini` + `checkpoints/`)의 PyTorch 체크포인트, `df.enhance.init_df`로 불러올 수 있어요 |
| `DeepFilterNet3_personal_onnx.tar.gz` | 인코더와 디코더 두 개를 ONNX로 내보낸 묶음. 공식 `DeepFilterNet3_onnx.tar.gz`와 같은 구조라서, 모델 묶음을 받는 libDF 기반 도구에서 쓸 수 있어요 |
| `DeepFilterNet3_personal_onnx.tar.gz.sha256` | SHA-256 |
| `report.json` | 아래 비교 결과 |

## 동작 방식

- **데이터**: 깨끗한 목소리 녹음에 내 소음 녹음을 −5~20 dB SNR로 섞고, 작은 말도 들어가도록 목소리
  크기를 30 dB 범위로 바꿔요. 예제의 15%는 잡음만(출력이 조용해야 함), 10%는 목소리만(출력이 그대로여야 함)이에요.
- **손실 함수**: DeepFilterNet의 압축 스펙트럼 손실(γ = 0.3). 목소리를 지워버린 쪽(과소 추정)에
  2배 가중치를 줘서, 숨소리를 지우기보다는 남기는 쪽을 택하게 해요.
- **최적화**: AdamW, 학습률 1e-4(코사인 감소), 그래디언트 클리핑 1.0, 4초 구간 8개씩.
  BatchNorm 통계는 고정해요. 방 하나의 몇 분짜리 녹음으로 통계가 치우치지 않게요.
- **검증**: 모든 녹음의 마지막 1/4은 학습에 쓰지 않아요. `finetune.py`는 그 부분으로 목소리 녹음과
  잡음 녹음을 10 dB SNR로 섞어서 다음을 보여줘요.
  - **voice cut**: 들리는 목소리 프레임 중 10 dB 넘게 깎인 비율 (낮을수록 목소리를 잘 살림)
  - 입력, 공개 모델, 튜닝 모델의 **SI-SDR** (높을수록 좋음)

  그리고 잡음만 넣었을 때 줄어든 양 (더 음수일수록 많이 지움)도 보여줘요.

  DeepFilterNet은 입력 레벨에 민감해서, 녹음이 작으면 가장 큰 목소리 녹음이 −26 dBFS가 되도록 마이크
  게인을 올린 경우로도 한 번 더 비교해요. `--eval-only`를 붙이면 `--out`에 있는 모델로 비교만 다시 해요.

## 예시 결과

한 사람의 목소리 4.2분(평소 말, 작은 말, 속삭임, 숨소리)과 잡음 3.8분(책상, 키보드, 마우스),
작게 녹음된 마이크 신호(평소 말이 약 −44 dBFS). 2000 스텝, RTX 5070 Ti에서 약 3.5분.
학습에 쓰지 않은 마지막 1/4로, 목소리 + 잡음 10 dB SNR, 잡음 세 종류 평균이에요.

| 목소리 | 레벨 | 목소리 깎임, 공개 → 튜닝 | SI-SDR dB, 입력 / 공개 / 튜닝 |
| --- | --- | ---: | ---: |
| 평소 말 | 녹음 그대로 | 97.0% → 8.7% | 4.4 / −8.3 / **20.4** |
| 평소 말 | 게인 +18 dB | 16.9% → 11.3% | 5.1 / 17.7 / **20.7** |
| 작은 말 | 녹음 그대로 | 100% → 0.0% | 3.5 / −13.8 / **19.8** |
| 작은 말 | 게인 +18 dB | 10.7% → 1.8% | 3.8 / 12.7 / **19.7** |
| 숨소리 | 녹음 그대로 | 94.1% → 2.4% | 4.5 / −8.8 / **13.4** |
| 숨소리 | 게인 +18 dB | 100% → 4.4% | 8.4 / −30.1 / **12.5** |
| 속삭임 | 녹음 그대로 | 95.3% → 29.7% | 5.6 / −7.8 / **−3.2** |
| 속삭임 | 게인 +18 dB | 76.3% → 58.2% | 7.4 / −7.5 / **−6.3** |

| 잡음만, 줄어든 양 | 녹음 그대로: 공개 / 튜닝 | 게인 +18 dB: 공개 / 튜닝 |
| --- | ---: | ---: |
| 책상 | −61.8 / −31.1 dB | −46.7 / −40.8 dB |
| 키보드 | −68.1 / −58.0 dB | −37.3 / −64.9 dB |
| 마우스 | −41.6 / −40.1 dB | −54.6 / −44.8 dB |

알 수 있는 것:

- **여기서 공개 모델이 목소리를 많이 지운 건 상당 부분 레벨 때문이에요.** 작은 신호에서는 목소리를
  거의 다 지웠지만, 게인을 올리면 평소 말과 작은 말은 대부분 살려요. 녹음하기 전에 평소 말이 −26 dBFS
  근처가 되도록 마이크 게인을 맞추세요.
- **그래도 파인튜닝은 두 레벨 모두에서 도움이 돼요.** 숨소리를 지우지 않고 살리고(게인을 올렸을 때
  깎임 100% → 4%), 작은 말은 거의 다 살리고, 평소 말과 작은 말의 SI-SDR이 3~7 dB 높아요.
- **속삭임은 여전히 어려워요.** 튜닝 모델이 속삭임 프레임을 더 많이 살리지만 두 모델 모두 속삭임의
  모양을 바꾸고(SI-SDR이 입력보다 낮음), 학습하지 않은 레벨에서는 효과가 줄어요.
- **얻는 게 있으면 잃는 것도 있어요.** 어떤 잡음은 덜 지우고(책상), 어떤 잡음은 더 지워요(게인을 올렸을 때 키보드).

목소리 × 잡음 조합별 전체 결과(두 레벨): [results/](results/README.md).

이 수치는 한 사람, 마이크 하나, 방 하나의 결과예요. 내 녹음으로 `finetune.py`를 돌리고,
바꾸기 전에 `enhance.py`로 꼭 들어보세요.

## 개인정보

녹음은 내 PC에만 남아요 (`data/`, `out/`은 git에서 제외돼 있어요). 튜닝된 가중치는 내 목소리로
학습한 것이니 공유하기 전에 한 번 더 생각하세요. 권리가 있는 목소리로만 학습하세요.
